# Berning_Fukasawa_etal
Code to reproduce figures in the manuscript

This repository contains a notebook to generate figures for the Visium HD analysis in the paper: Berning, Fukasawa, et al. CXCR6+ T cells are required for CD3xCD20 Bispecific Antibody Efficacy in B cell Lymphomas (2026). _Unpublished_.

Processed data can be downloaded from the associated GEO accession.
